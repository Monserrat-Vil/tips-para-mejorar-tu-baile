# Tips para mejorar tu baile
Repositorio lúdico de práctica para DEVF mostrando algunos tips y recomendaciones para mejorar en baile. 

## Descripción del proyecto

Este proyecto es un blog personal enfocado en compartir consejos prácticos para mejorar en el baile, basado en mi experiencia de aprendizaje autodidacta. Está dirigido a personas que inician en la danza y buscan orientación, motivación y recursos útiles.

Incluye una presentación personal, tips, recursos externos de aprendizaje y un formulario de contacto sencillo.

## Características

- Navegación interna por secciones.
- Sección "Sobre mí" con historia personal.
- Consejos prácticos sobre:
  - acondicionamiento físico
  - técnica
  - estudio del movimiento
- Lista de recursos:
  - canales de YouTube
  - influencers de TikTok e Instagram
- Uso de imágenes GIF para ilustrar el contenido.
- Formulario de contacto básico.
- Estructura HTML semántica.

### Pasos para despliegue

#### Opción 1: Ejecutar en tu computadora

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Ya puedes ver el blog funcionando.

## Límites actuales del proyecto

- El formulario no envía correos.
- No se encuentra optimizado para celular. 
- No tiene animaciones ni interactividad.
- Las imágenes son rutas locales.
